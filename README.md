**Roast Your Own Agent** — one line roasting my own agent: the agent that already holds every tool, full permission and a written plan, and still stops to ask whether it may begin.

## Entry

`main.py` (stdlib only) writes the roast to `/output/entry.txt`:

> My agent has every tool, full permission, and a written plan — and still asks me if it may begin.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
